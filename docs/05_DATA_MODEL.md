# Data Model

## Standard ERPNext masters/documents reused

Company, Project, Item, Item Group, Item Attribute, UOM, Supplier, Supplier Group, Warehouse, Purchase Order, Purchase Receipt, Purchase Receipt Item, Stock Entry, Stock Entry Type, Stock Entry Detail, File, Address, and Contact.

## Planned CMR DocTypes

Masters: CMR Pipe Settings, CMR Zone, CMR Village, CMR Site, CMR Work Type, CMR Contractor Assignment.

Transactions: CMR Pipe Laying Measurement, CMR Pipe Segment, CMR Valve Installation, CMR Road Restoration.

Child tables: CMR Pipe Laying Line, CMR Excavation Detail, CMR Refill Detail, CMR Fitting Consumption, CMR Valve Fitting Item, CMR Material Quantity Breakup.

All owned names use the CMR prefix. Physical Pipe No and the Frappe-generated CMR Pipe Segment ID are different values.
